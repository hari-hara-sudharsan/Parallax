# Full-loop proofs: origin event → reactive tx → callback tx

> **Naming note:** the project was renamed from its working name *Tripwire* to **Parallax** on 2026-11-15 (another buildathon entry uses that name). Deployments v1/v2 and Runs 1–3 below were made before the rename: same code, same events; only identifiers changed.

Each row is one complete, unattended Parallax execution on testnet. No keeper and no script triggered the callback:
Reactive Network saw the origin event and did the rest. Reproduce any row with `./tw.sh proof <originTx>`.

## Headline: v3 live benchmark (multi-chain, 2026-11-15)

**44 / 44 live rounds filled, no keeper, real Uniswap v4.** Full per-round table with every tx hash:
[`results/SUMMARY.md`](../results/SUMMARY.md) (generated by `bench/bench.mjs`).

| Chain | Block time | Rounds | Filled | Median origin → execution | p90 | Fastest |
|---|---|---|---|---|---|---|
| **Base Sepolia** | 200 ms | 32 | **32/32** | **7 blocks ≈ 1.4 s** | 10 blocks ≈ 2.0 s | 5 blocks ≈ 1.0 s |
| Unichain Sepolia | 1 s | 12 | **12/12** | 2 blocks ≈ 2.0 s | 3 blocks ≈ 3.0 s | 2 blocks |

Block counts come from each executor's on-chain `Execution` record (`executedBlock − originBlock`), so they are exact.
One ParallaxReactive on Lasna served both chains during the whole run. A first Unichain attempt was invalidated by a
benchmark-script bug (Flashblocks receipts); it is kept, with the explanation, in
[`results/invalid/`](../results/invalid/README.md).

## How to add a row

```bash
./tw.sh create-stop-loss      # or create-take-profit / create-range-guard
./tw.sh push-down             # or push-up. Copy the swap tx hash from contracts/broadcast/04_PushPrice.s.sol/1301/run-latest.json
./tw.sh proof <originTx>      # prints origin / reactive / callback tx + latency
```

Note: `SYSTEM.getCallbacks(reactiveTx)` returned an empty list on Lasna, so the proof links via the origin tx hash that
`RuleExecuted` carries.
